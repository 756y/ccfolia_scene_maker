## 這次更新了什麼？

- **可以匯入 ZIP**：選擇 Cocofolia Room ZIP，就能把裡面的場景和圖片帶進編輯器。
- **側邊欄可以收起來**：畫面想看大一點時，可以把左側功能欄收起來。
- **手機操作更方便**：可以使用長按選單來複製、貼上或刪除。
- **匯入時會讀取前景尺寸**：匯入後會一起帶入前景的寬、高和相關設定。
- **保留原本的編輯功能**：像是新增場景、放置圖片、調整大小、複製、復原和匯出等功能都還在。

## 使用方法

### 1. 開始使用

打開 HTML 檔就可以使用，不用另外安裝程式。

編輯器會在畫面中顯示場景畫布，左側是主要功能區。可以先新增場景，再把需要的圖片放進來。

### 2. 新增圖片

- **新增畫面元件／插分**：把圖片放進目前場景，可以移動、縮放和旋轉。
- **新增共享元件**：建立可以在不同場景中重複使用的圖片元件。
- **背景**：設定目前場景的背景圖片。
- **前景**：設定會覆蓋在場景上方的圖片，例如遮擋視線用的圖層。

上傳圖片後，可以再調整它的位置和大小。

### 3. 選取、移動和調整圖片

- 點一下圖片即可選取。
- 拖曳圖片可以移動位置。
- 使用圖片周圍的控制點調整大小。
- 使用浮動工具列中的功能，可以進一步操作選取的圖片。
- 點畫布空白處可以取消選取。

如果圖片不好選取，可以先確認它有沒有被其他圖片擋住。

### 4. 複製、貼上和刪除

- 選取圖片後，使用工具列或側邊功能中的複製、貼上和刪除功能。
- 需要一次處理多個元件時，可以先開啟多選，再選取要操作的元件。
- 手機或觸控裝置也可以長按，叫出複製、貼上、刪除選單。

### 5. 多選元件

開啟多選功能後，可以選取多個圖片元件，再一起移動或進行支援的操作。

要單獨調整某一張圖片時，先取消多選，再選取那張圖片即可。

### 6. 管理場景

- 新增場景：建立新的場景。
- 切換場景：在場景列表中選擇要編輯的場景。
- 修改場景名稱：方便辨認不同場景。
- 刪除場景：移除不需要的場景。

切換場景後，記得確認目前編輯的是哪一個場景。

### 7. 設定場景大小和前景

打開「設定」可以調整場景尺寸。預設場景大小是 **1920 × 1080**，也可以依照需求自行修改。

前景相關設定可以調整：

- 前景寬度和高度
- 前景是否符合場景大小
- 前景是否配合格線對齊

修改後，記得查看畫布上的效果是否符合預期。

### 8. 縮放和移動畫布

- 使用畫布縮放功能調整觀看大小。
- 拖曳畫布可以移動目前的視野。
- 縮放畫布只會改變觀看比例，不會直接改變場景本身的尺寸。

### 9. 復原、重做和儲存

- **復原**：回到上一個操作前的狀態。
- **重做**：重新套用已復原的操作。
- 編輯器會儲存目前的編輯狀態；重要內容仍建議定期匯出備份。

如果畫面看起來突然不對，可以先試著復原，或切換場景後再確認。

### 10. 匯入 ZIP

1. 在左側功能區找到「匯入 ZIP」。
2. 選擇 Cocofolia Room ZIP 檔。
3. 等待匯入完成，並留意畫面上的狀態訊息。
4. 匯入後確認場景、圖片、背景和前景尺寸是否正確。

**注意：匯入 ZIP 會取代目前編輯器中的場景和元件。** 如果目前有還要保留的內容，請先匯出備份再匯入。

### 11. 匯出檔案

- **Room ZIP**：匯出場景資料和圖片資源，方便之後匯入 Cocofolia 或留作備份。
- **PNG**：把畫面匯出成一張圖片，適合預覽或分享。

如果之後還想繼續編輯，建議保留 Room ZIP；單純要看畫面或分享時，可以匯出 PNG。

### 12. 收起側邊欄

點擊設定旁邊的側邊欄按鈕，就可以收起或展開左側功能欄。需要更大的畫布空間時，可以先把它收起來。

### 13. 初始化編輯器

「初始化編輯器」會清除目前的編輯內容，重新建立空白場景。使用前請先匯出需要保留的內容，避免把作品清掉。

---

## 小提醒

- 匯入 ZIP 前，先備份目前的工作。
- 圖片上傳後如果找不到，可以確認是否被其他元件遮住，或切換到正確的場景。
- 匯出 Room ZIP 和匯出 PNG 的用途不同：前者保留可匯入的場景資料，後者是單張圖片。
