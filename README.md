## 1. 開始使用

1. 將 `場景編輯器v2.10.html` 保存在裝置中。
2. 使用支援現代 JavaScript、圖片檔案讀取及瀏覽器儲存功能的瀏覽器開啟 HTML 檔。
3. 等待編輯器載入。第一次使用時會建立「場景 1」；如果此瀏覽器之前已有自動儲存資料，則會嘗試還原先前的編輯內容。
4. 建議先新增背景，再放置畫面元件與場景標誌，最後調整圖層並匯出。

這是單一 HTML 檔案的編輯器。自動儲存資料存在目前瀏覽器的本機儲存空間，不等同於另存一份專案檔；若要備份或交付成果，請另外匯出 Room ZIP 或 PNG。

## 2. 介面概覽

左側是控制面板，右側是工作區／無邊界畫布。

### 左側控制面板

- **新增元件**：匯入畫面元件、場景標誌、背景及前景。
- **元件列表**：分開列出「畫面元件」及「場景標誌元件」，可以直接點選列表項目。
- **選取物件**：調整目前選取圖片的名稱、位置、尺寸、圖層、旋轉與透明度。
- **場景**：新增、切換、重新命名、刪除場景，並清除目前場景的背景或前景。
- **輸出**：匯出 Room ZIP、PNG，或初始化編輯器。
- **⚙ 設定**：調整目前場景尺寸、前景尺寸、格線、吸附與快捷工具列圖示顯示。

### 工作區底部控制列

- **↶**：返回上一步。
- **↷**：重做下一步。
- **▧+**：切換多選模式。
- **縮放滑桿／百分比**：調整畫布顯示比例。
- **適合畫布**：讓整個場景盡量完整顯示於工作區。
- **100%**：將檢視縮放恢復為 100%。
- 選取圖片時，快捷工具列會出現在底部控制列旁邊；未選取物件時會隱藏。

## 3. 新增圖片與理解元件分類

### 3.1 畫面元件

1. 點選「新增元件」中的 **畫面元件**。
2. 在檔案選擇視窗選取圖片。
3. 匯入完成後，圖片會加入左側「畫面元件」列表，並顯示在目前場景。
4. 這類元件屬於**全場景共用**：切換場景時仍會出現在其他場景中，適合角色、家具、道具、裝飾等共用物件。

### 3.2 場景標誌元件

1. 點選 **場景標誌**。
2. 選取要匯入的圖片。
3. 元件會加入「場景標誌元件」列表。
4. 這類元件只屬於目前場景，切換到其他場景時不會跟著出現，適合只在某個房間或場景使用的標記、地形或特殊物件。

> **如何選擇？** 若同一個物件預計出現在多個場景，使用「畫面元件」；若只應出現在目前場景，使用「場景標誌」。

### 3.3 設定背景

1. 點選 **設定背景**。
2. 選取背景圖片。
3. 背景會填滿工作區周圍的背景顯示區，並以模糊效果呈現；背景資料屬於目前場景。
4. 如要移除，於「場景」區塊點選 **清除背景**。

背景不是一般可拖曳的元件，不會出現在一般元件的選取控制項中。切換場景後，每個場景可使用各自的背景。

### 3.4 設定前景

1. 點選 **設定前景**。
2. 選取前景圖片。
3. 前景會依設定中的前景寬度、高度與顯示方式呈現。
4. 如要移除，點選 **清除前景**。

前景屬於目前場景的獨立圖層，不是一般可選取、拖曳的畫面元件。前景大小可在「設定」中以格數調整，詳細說明見[場景設定](#8-場景設定)。

## 4. 選取、移動與調整元件

### 4.1 選取元件

- 在畫布上點擊圖片，或直接點擊左側對應的元件列表項目，即可選取。
- 選取後，左側「選取物件」會顯示圖片預覽與編輯欄位。
- 選取的圖片周圍會出現選取外框及縮放控制點；取消選取後，這些選取提示應一併消失。
- 若物件已鎖定，請先在快捷工具列解除鎖定，再進行移動或編輯。

### 4.2 移動元件

1. 將游標／手指放在已選取的圖片上。
2. 按住並拖曳到新位置。
3. 若「拖曳時自動吸附格線」已開啟，拖曳位置會依格線吸附；關閉後則可自由移動。

畫布的平移與縮放只改變觀看位置，不會改變物件在場景內的座標。請避免把「移動畫布」和「移動圖片」混為一談。

### 4.3 精確調整欄位

選取物件後，可在左側直接輸入：

- **名稱**：方便辨認物件，名稱也會出現在元件列表。
- **X 座標、Y 座標**：調整物件在場景中的位置。
- **寬度、高度**：設定物件尺寸。
- **圖層 Z**：設定物件圖層排序數值；數值較高的物件通常會顯示在較上層。
- **旋轉**：輸入角度，或使用旋轉滑桿調整。
- **透明度**：使用滑桿設定 0% 至 100%；0% 幾乎完全透明，100% 為完全不透明。

也可以使用圖片周圍的控制點直接拖曳縮放。若需要精確尺寸，建議搭配寬度與高度欄位。

## 5. 浮動快捷工具列

選取單一物件時，底部控制列旁會顯示快捷工具列。各按鈕用途如下：

| 功能 | 說明 |
|---|---|
| 水平鏡像 | 將圖片左右翻轉。 |
| 垂直鏡像 | 將圖片上下翻轉。 |
| 更換圖片 | 選取另一張圖片取代目前圖片；原本的位置、尺寸、旋轉、透明度、鏡像及圖層設定會保留，物件名稱會更新為新圖片檔名。 |
| 顯示／隱藏 | 切換一般畫面元件的可見狀態。場景標誌不提供此按鈕。 |
| 鎖定／解鎖 | 鎖定後避免不小心移動物件；需要編輯時再解除鎖定。畫面元件與場景標誌都可鎖定。 |
| 移到最上層 | 將物件放到最上方圖層。 |
| 上移一層 | 將圖層 Z 值提高一層。 |
| 下移一層 | 將圖層 Z 值降低一層。 |
| 移到最下層 | 將物件放到最下方圖層。 |
| 複製物件 | 建立目前物件的副本。 |
| 刪除物件 | 刪除目前選取的物件。 |

### 自訂快捷工具列

1. 點選左上方 **⚙ 設定**。
2. 找到「圖片浮動工具列顯示項目」。
3. 勾選或取消勾選想顯示的圖示。
4. 關閉設定面板即可回到工作區。

取消勾選只會隱藏該圖示，不會停用功能本身。預設會顯示全部項目。

## 6. 多選元件

多選模式適合一次移動多個物件。

1. 點選工作區底部的 **▧+** 按鈕，開啟多選模式；按鈕會呈現啟用狀態，畫布游標也會改變。
2. 在畫布的空白處按住並拖曳，拉出框選範圍。
3. 放開滑鼠／手指後，框選範圍內符合條件的未鎖定元件會被選取。
4. 拖曳選取的元件，可一起移動。
5. 再次點擊 **▧+** 可關閉多選模式。

注意：鎖定的物件不會被多選拖曳一起移動。多選模式主要用於框選與群組移動；若要精確修改單一物件的名稱、尺寸、旋轉或透明度，請先切回一般模式並單獨選取物件。

## 7. 場景管理

### 7.1 新增場景

1. 在左側「場景」區塊點選 **＋ 新增場景**。
2. 新場景會插入目前場景之後，並自動切換至新場景。
3. 新場景會沿用原場景的背景、前景設定與場景標誌（標誌物件會建立新的識別資料）；全場景共用的畫面元件本來就會在各場景顯示。
4. 在「場景名稱」欄位輸入容易辨識的名稱，例如「教室」、「走廊」或「餐廳」。

### 7.2 切換場景

點擊場景列表中的場景即可切換。切換後，工作區會載入該場景的背景、前景與場景標誌；共用畫面元件仍會顯示。

### 7.3 調整場景順序

場景列表項目左側有拖曳把手。按住把手並拖曳，可調整場景在列表中的順序。場景編號會依列表顯示順序呈現。

### 7.4 刪除場景

1. 先切換到要刪除的場景。
2. 點選 **刪除場景**。
3. 編輯器至少會保留一個場景，因此最後一個場景不能刪除。

刪除前請確認該場景內的背景、前景及場景標誌是否仍需要；若需要，請先匯出備份。

### 7.5 清除背景或前景

在場景區塊中點選 **清除背景** 或 **清除前景**，只會清除目前場景對應的圖層，不會直接清除其他場景的背景或前景。

## 8. 場景設定

點選左側標題旁的 **⚙ 設定** 開啟設定面板。

### 8.1 場景大小

- 預設為 **1920 × 1080 像素**。
- 可分別修改場景寬度與高度，最小值為 1 像素。
- 尺寸設定屬於目前場景；若各場景需要不同尺寸，請切換到該場景後分別設定。

更改場景尺寸會改變場景畫布的工作範圍。完成後建議按「適合畫布」重新調整檢視比例。

### 8.2 前景大小

前景寬度與高度以格數設定，每格為 **24 × 24 像素**。例如寬度 40 格相當於 960 像素，高度 30 格相當於 720 像素。

- **圖片符合前景尺寸**：勾選時，圖片會以等比例方式縮放並裁切至指定範圍；取消勾選時，圖片會直接拉伸至指定尺寸。
- 前景尺寸與顯示方式屬於目前場景。

### 8.3 拖曳時自動吸附格線

- **開啟**：拖曳物件時會吸附至格線，方便對齊。
- **關閉**：物件可以自由移動，不必對齊格線。

### 8.4 顯示格線

勾選可顯示場景內的格線；取消勾選可隱藏格線。這是編輯輔助顯示，不是額外的圖片元件。

### 8.5 浮動工具列顯示項目

依照[浮動快捷工具列](#5-浮動快捷工具列)的說明，設定各圖示是否顯示。隱藏圖示不會關閉其功能。

## 9. 畫布檢視與操作

### 9.1 平移畫布

在工作區空白處按住並拖曳，可移動整個畫布的觀看位置。平移不會更改物件座標。

### 9.2 縮放畫布

- 拖曳底部的縮放滑桿調整比例，範圍為 **10% 至 200%**。
- 點選 **適合畫布**，讓整個場景盡可能完整顯示在工作區。
- 點選 **100%**，將顯示比例重設為 100%。

縮放只影響工作區的檢視大小，不會直接改變圖片本身的寬度、高度或座標。

## 10. 復原、重做與自動儲存

### 10.1 復原與重做

- 點選 **↶** 返回上一步。
- 點選 **↷** 重做已復原的操作。
- 鍵盤快捷鍵：`Ctrl+Z` 復原、`Ctrl+Y` 重做；也支援 `Ctrl+Shift+Z` 重做。在 macOS 等使用 Command 鍵的環境中，程式也會接受對應的修飾鍵操作。
- 歷史紀錄最多保留最近 **30 個資料變更動作**。一次拖曳或縮放會合併為一次操作紀錄。

並非每個純檢視操作都會形成復原紀錄；復原主要針對場景與物件資料的變更。

### 10.2 自動儲存

編輯器會定期自動儲存，間隔約 **10 秒**，並在工作區底部顯示儲存狀態與最後儲存時間。資料優先存入瀏覽器 IndexedDB；若不可用或儲存失敗，會嘗試使用 localStorage。

- 下次在同一瀏覽器環境開啟編輯器時，程式會嘗試還原自動儲存內容。
- 自動儲存不是跨裝置同步，也不是獨立的專案下載檔。
- 清除瀏覽器網站資料、使用不同瀏覽器／瀏覽器設定檔，或瀏覽器儲存空間不足，都可能導致資料無法還原。
- 重要成果請定期匯出 Room ZIP 或 PNG，另存備份。

### 10.3 初始化編輯器

「輸出」區塊中的 **初始化編輯器** 會先顯示確認提示。確認後會清除目前所有場景、共用畫面元件、場景標誌、背景與前景，並建立全新的「場景 1」，同時清除原有自動儲存資料。

**這項操作會清除目前專案內容。請先匯出需要保留的成果，再進行初始化。**

## 11. 匯出成果

### 11.1 匯出 Room ZIP

1. 完成場景、背景、前景及元件配置。
2. 點選「輸出」中的 **Room ZIP**。
3. 等待編輯器整理場景與圖片資源並建立 ZIP 檔。
4. 依瀏覽器提示儲存下載的檔案。
5. 將 ZIP 匯入 Cocofolia 時，請依 Cocofolia 當前版本所提供的 Room 匯入流程操作。

Room ZIP 是供 Cocofolia Room 資料使用的匯出格式，會整理場景與圖片資源；它不是一般圖片預覽檔。建議匯出後保留原始 ZIP 作為備份。

### 11.2 匯出 PNG

1. 點選 **PNG**。
2. 等待圖片繪製完成並下載。
3. 下載檔名為 `cocofolia_scene.png`。

PNG 適合用來預覽、分享或留存目前場景的合成畫面。它是平面圖片，不能像 Room ZIP 一樣保留可獨立編輯的物件與場景資料。

### 11.3 匯出前檢查清單

- [ ] 場景名稱與場景順序正確。
- [ ] 背景、前景與場景標誌都放在正確場景。
- [ ] 全場景共用的畫面元件已確認。
- [ ] 物件沒有被誤隱藏或鎖定。
- [ ] 圖層順序、尺寸、位置、旋轉與透明度正確。
- [ ] 已先匯出備份，才執行初始化或大幅修改。

## 12. 常見問題與注意事項

### 點不到或拖不動圖片？

先確認是否選到了正確物件，以及物件是否已鎖定。鎖定物件時，先選取它並在快捷工具列解除鎖定。若目前處於多選模式，點擊 **▧+** 關閉後再嘗試一般選取。

### 切換場景後，為什麼某些圖片還在？

「畫面元件」是全場景共用，因此切換場景仍會顯示；「場景標誌」才是目前場景專用。請依物件用途選擇正確分類。

### 為什麼看不到快捷工具列？

快捷工具列只會在選取物件時顯示。若已選取仍看不到某個按鈕，請到「設定」確認該圖示是否被隱藏。

### 為什麼圖片移動時會對齊格線？

這是「拖曳時自動吸附格線」功能。到設定面板取消勾選即可自由移動。

### 為什麼重新開啟後內容不一樣或沒有還原？

自動儲存綁定目前瀏覽器的本機儲存。請確認使用同一瀏覽器與設定檔，並避免清除瀏覽器資料。若內容很重要，請以 Room ZIP 或 PNG 另行備份。

### Room ZIP 與 PNG 有什麼不同？

- **Room ZIP**：用於 Cocofolia Room 匯入，保留場景資料與圖片資源的結構。
- **PNG**：合成後的單張圖片，方便查看或分享，但不是可繼續編輯的專案資料。

### 初始化後可以還原嗎？

初始化會清除目前資料與自動儲存內容。請勿把初始化當成一般清空選取或清除背景的操作；執行前務必先匯出備份。
